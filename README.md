# Aura OS

A cinematic **virtual computer** running entirely in your browser.

Dark cosmic theme • Glassmorphism windows • Particle background • Working apps

## Features

- **Boot sequence** with ambient glow
- **Desktop** with icons + floating particles
- **Draggable windows** (drag by title bar)
- **Taskbar** + Start menu
- **Apps**:
  - Terminal (with fun commands: `neofetch`, `aura`, `matrix`...)
  - Notepad
  - About
  - Settings
- Fully responsive feel

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Just push to GitHub and connect to Vercel — zero config.
